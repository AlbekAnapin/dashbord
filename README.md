# Дашборд качества данных ОВПО

Статический сайт (только HTML + CSS + JavaScript, без сервера и сборки). Загружаете Excel-срез «Не корректные данные» —
сайт разбирает все листы прямо в браузере и показывает сводный рейтинг, рейтинг по качеству, динамику и карточку каждого ОВПО.
Файлы никуда не отправляются.

## Что внутри

| Вкладка | Что показывает |
|---|---|
| Обзор | KPI, топ-15 проблемных ОВПО, структура ошибок по источникам, распределение баллов, средний балл по показателям, динамика |
| Рейтинг по качеству | Баллы 0–100 по критериям «Корректность / Заполненность / Исполнение», итог, ранги, изменение к выбранному срезу, выгрузка в Excel |
| Сводный рейтинг ошибок | «ОВПО / Общее количество ошибок», % от общего числа, накопленный %, разбивка по источникам, включение/выключение источников, выгрузка в Excel |
| Динамика | Графики по срезам, таблица «ошибки по источникам и срезам», ОВПО с лучшей и худшей динамикой |
| ОВПО | Карточка организации: поиск по названию, баллы, ранги, топ-12 полей с ошибками и **подробная расшифровка по каждому листу**: какие поля не заполнены или заполнены некорректно, сколько ошибок по каждому полю, в разрезе годов, категорий (обучающиеся / отчисленные / выпускники), общежитий и административных отчётов |
| Данные и настройки | Загрузка срезов, список действующих ОВПО, веса критериев, публикация (bundle.js), методика |

## Детализация по полям (вкладка «ОВПО»)

* **Поиск:** начните вводить название в поле поиска (достаточно части слов, например «казах педаг»), стрелки ↑↓ и Enter — выбор.
* **Разделы по листам:** ГБД ФЛ (обучающиеся, выпускники, ППС — по каждому типу ошибки), ОСМС (категории и поля), Генерация дипломов (по годам),
  Дубли ИИН (в том числе с какими вузами и сколько), Оцифровка (по полям и по годам выпуска), GPA (по степеням и годам выпуска), ППС, МТБ, Госуслуги, Админ. отчёты.
* Для каждого поля: число ошибок, % от итога таблицы, сумма по всем ОВПО и доля данного ОВПО. Можно скрывать поля без ошибок и сортировать по убыванию.
* ОСМС и GPA разделены на категории (ОСМС — обучающиеся / отчисленные / выпускники; GPA — обучающиеся / выпускники) в сводном рейтинге и в карточке ОВПО.
  На баллы рейтинга по качеству разделение не влияет (там остаётся общий итог).
* Подписи некоторых столбцов в исходном Excel обрезаны. Для ГБД ФЛ (обучающиеся) они восстановлены по блоку выпускников, одинаковые названия различаются буквой столбца.
* Срезы, сохранённые прежней версией сайта, не содержат детализации: загрузите исходный файл заново.

## Как открыть и проверить у себя (до публикации)

1. Распакуйте архив.
2. Дважды щёлкните `index.html` (Chrome, Edge, Firefox). Интернет не нужен: библиотека чтения Excel лежит в `assets/`.
3. Перетащите Excel-файл(ы) среза в окно. Можно сразу несколько срезов — тогда заработает динамика.
4. Файл со списком действующих ОВПО (названия в первом столбце, заголовок «ОВПО») тоже можно просто перетащить —
   он распознаётся автоматически. Либо загрузите его на вкладке «Данные и настройки».
5. Вкладка «Данные и настройки» → блок «Проверка разбора» показывает, какие листы найдены и сколько строк прочитано.
   Если структура листа изменилась, там появится предупреждение.

## Публикация на GitHub Pages для сотрудников

1. Создайте репозиторий на GitHub и загрузите в него **содержимое этой папки** (`index.html`, `assets/`, `data/`, `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт появится по адресу `https://<аккаунт>.github.io/<репозиторий>/`. Эту ссылку и отправляйте сотрудникам.
4. **Чтобы сотрудники видели данные без загрузки файлов:** откройте сайт у себя, загрузите срезы, на вкладке
   «Данные и настройки» нажмите **«Скачать bundle.js»**, замените этим файлом `data/bundle.js` в репозитории и сделайте commit.
   После этого любой, кто откроет ссылку, сразу увидит все дашборды.
5. Обновление данных: загрузили новый срез → «Скачать bundle.js» → заменили `data/bundle.js` → commit. Всё.

### Важно про конфиденциальность
* В `bundle.js` попадают только итоговые числа по ОВПО (без ИИН, ФИО и ID). Но сами данные служебные.
* Сайт на GitHub Pages по умолчанию **доступен всем, у кого есть ссылка**. Если публиковать открыто нельзя, используйте
  вариант с ограничением доступа (корпоративные планы GitHub) или внутренний веб-сервер: сайт — обычная папка со статическими файлами,
  подойдёт любой хостинг.

## Какие листы ожидаются в Excel

ГБД ФЛ · ОСМС · Генерация номеров дипломов · Дублирование записей по ИИН · Оцифровка дипломов · GPA не заполнен ·
Полнота данных ППС · Материально-техническая база · Государственные услуги · Административный отчет.

Колонки ищутся **по названиям заголовков**, а не по номерам, поэтому небольшие изменения порядка столбцов не ломают разбор.
Лист «Государственные услуги» — столбец «Итого (кол-во срок обработки заявки истек)»; формат «Принято / Отклонено» не поддерживается.
Срезы в старом формате (28.10) читаются частично: отсутствующие листы (GPA, админ. отчёты) отмечаются как «нет листов» и не считаются нулём.

## Структура папки

```
index.html            страница
assets/core.js        разбор Excel и расчёт рейтингов (без привязки к интерфейсу)
assets/charts.js      графики на чистом SVG
assets/app.js         интерфейс
assets/style.css      оформление (светлая и тёмная тема)
assets/xlsx.full.min.js   SheetJS 0.18.5 — чтение/запись Excel
data/bundle.js        опубликованные данные (заменяется при обновлении)
```

## Что можно настроить в коде

* Показатели, критерии и список источников сводного рейтинга — массивы `INDICATORS` и `UCOLS` в `assets/core.js`.
* Названия-варианты одного ОВПО (например, «Академия КНБ РК») — `ALIAS_RULES` там же.
* Порог «красной зоны» на обзоре — константа `RED_ZONE` в `assets/app.js`.
